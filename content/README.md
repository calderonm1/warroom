# content/: data-driven game content

All nations, units, research, buildings, maps and balance numbers live here as YAML, validated against JSON Schemas in `shared/content-schema/`. The setting is **modern day** at launch. Other settings (historical, near-future, fictional) are added as new **content packs** without code changes ([ADR-0011](../docs/adr/0011-match-format-and-content-packs.md)).

```
content/
  packs/
    modern/                     launch pack
      pack.yaml                 id, version, display name, dependencies
      nations/*.yaml
      units/*.yaml
      buildings/*.yaml
      research/*.yaml
      resources.yaml
      maps/
        <map-id>/
          map.yaml              player count, coalition size, speed tiers, victory settings
          provinces.geojson     source geometry (generated by the geodata pipeline, human-reviewable)
          provinces.yaml        per-province gameplay data (terrain, resources, buildings, VP)
  localization/
    en/*.yaml
```

Content IDs are lowercase dotted paths: `unit.armor.mbt`, `nation.de`, `research.air.stealth_1`. See [naming conventions](../docs/05-conventions/naming.md).
