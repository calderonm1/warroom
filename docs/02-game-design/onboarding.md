# Onboarding and tutorial

| ID | Rule |
| --- | --- |
| GDD-ONB-001 | From first launch to the first command on the globe in **≤ 60 seconds**. No account creation required (guest). |
| GDD-ONB-002 | **Tutorial operation** (single-player, accelerated time, about 15 min): select a nation, move an army, capture a province, queue production, start research, win a battle with a combat preview, form a coalition with an AI ally, set a standing order. |
| GDD-ONB-003 | After the tutorial, offer: **Practice vs AI** (pausable) or **Join a 16-player beginner match** (accounts under level 5 are matched together when population allows). |
| GDD-ONB-004 | Day-1 to Day-3 **advisor tips** in the first real match: contextual, dismissible, max 1 per check-in. |
| GDD-ONB-005 | Prompt to link an account (Apple/Google) after the first match day or before the first purchase, never before. |
| GDD-ONB-006 | Notification permission is requested after the tutorial, with a pre-prompt explaining value ("Know when your armies arrive"). |
