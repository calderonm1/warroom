# Voice and copy guidelines

| ID | Rule | Example |
| --- | --- | --- |
| COPY-001 | Terse, confident, briefing-style. Lead with the fact, then the action. | "Armor Bn arrived in Kraków. Orders?" |
| COPY-002 | Address the player as Commander sparingly (notifications, briefing headers). | "Commander, your capital is under attack." |
| COPY-003 | Use glossary terms exactly ([glossary](../00-product/glossary.md)). | "Army", not "stack", in UI |
| COPY-004 | Numbers are concrete; durations use short units. | "2h 14m", "Day 6" |
| COPY-005 | Errors say what happened and what to do; never blame the player. | "Can't move there: no path through hostile territory. Try via Gdańsk." |
| COPY-006 | No gore, no glorification of real atrocities, no real political figures. | |
| COPY-007 | Store copy is honest about what is cosmetic. | "Cosmetic only. No gameplay advantage." |
| COPY-008 | Sentence case for UI labels; ALL CAPS only for section labels and the logo. | "Start research" |
| COPY-009 | Push notifications ≤ 90 characters, location first. | "Kyiv: hostile armor spotted 40 km east." |
